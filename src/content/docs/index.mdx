The framework follows three key approaches: **contract first**, **everything as code**, and **shift left**. The contract-first approach recognizes contracts as a primary outcome and a source of truth. The everything-as-code approach treats code as a primary medium. The shift-left approach moves practices and tools closer to developers.

The framework identifies four pillars: **circulation** and **consistency**, evolutionary pillars for developer productivity; **continuity** and **conformance**, operational pillars for customer satisfaction.

:::tip[Getting started]

1. Share contracts via a **registry** for circulation.
2. Enforce decisions via a **linter** for consistency.
3. Detect changes via a **detector** for continuity.
4. Inspect behaviors via a **proxy** for conformance.

:::
