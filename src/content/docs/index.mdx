The framework follows three principles:

- **Contract first** recognizes contracts as a primary outcome and a source of truth.
- **Everything as code** treats code as a primary medium.
- **Shift left** moves practices and tools closer to developers.

The framework identifies four pillars:

- **Circulation** and **consistency**: evolutionary pillars for developer productivity.
- **Continuity** and **conformance**: operational pillars for customer satisfaction.

:::tip[Getting started]

1. Share contracts via a registry for circulation.
2. Enforce decisions via a linter for consistency.
3. Detect changes via a detector for continuity.
4. Inspect behaviors via a proxy for conformance.

Start lean: use a shared repository as the first registry, and adopt [skills](/api4c-framework/practices/skills/) as ad hoc linters and detectors.

:::
